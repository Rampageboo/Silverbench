# Retarget profiles

Arbitrary target-rig retarget profiles remain deferred. Character-reference
profiles are a different, implemented contract: `profile.json` has
`role: source_character_reference` and supplies guarded proportions only while
observations are refined. It never changes the Canonical Motion or target-rig
schemas. Target playback, native model preview, and FBX retargeting remain later
milestones.
