# Motion viewport human reference

`human_outline_generic.png` is a transparent raster copy of the CC0 standing
human outline used as a subdued visual reference behind the live skeleton.
`human_outline_generic.svg` is the unmodified source copy.

- Source: https://commons.wikimedia.org/wiki/File:Human_outline_generic.svg
- Direct source file: https://upload.wikimedia.org/wikipedia/commons/7/79/Human_outline_generic.svg
- License: CC0 1.0 Universal Public Domain Dedication
- Retrieved: 2026-08-20

The reference layer is presentation-only. It does not modify pose data,
confidence values, alignment, smoothing, or exported motion.
