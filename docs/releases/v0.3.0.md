AI-assisted annotation review and gallery captions.

- Label workbench: open **AI review → Open full review** to request independent box proposals from OpenAI or Claude. Inspect the overlay, accept individual boxes into the existing editor, or reject them. Decisions survive reloads. Changed source images or class definitions require a fresh review.
- Gallery: generate a caption and tag corrections, edit the suggestions, explicitly select tag removals, and apply them to a draft. **Save** persists the reviewed caption/tags; **Discard** leaves saved data unchanged. Original generation metadata is retained.
- Cloud APIs are optional and off by default. Each request needs explicit upload consent. Configure provider model, current token rates and request/batch/monthly budgets in the review controls. Interrupted calls are not retried automatically; usage estimates and review decisions are kept locally.
- Bring your own API key: set `OPENAI_API_KEY` or `ANTHROPIC_API_KEY` in the environment inherited by the installed app, then restart it. Keys and test data are not included in the installer. Developer checkouts can use an ignored `.env.local`; see [API setup](https://github.com/Rampageboo/Silverbench/blob/v0.3.0/docs/ai-review-api.md).
- The MCP server adds `review_image_with_api`, using the same backend consent and budget controls. Local inference and existing workflows remain available without cloud APIs.

Validation: 651 frontend tests, production frontend build, 65 targeted backend/API/MCP/gallery tests, desktop/compact browser interactions and real OpenAI calls using a synthetic image. Claude live calls and real-dataset accuracy are not yet validated. AI geometry is approximate and requires human review. Budget figures are usage estimates, not a provider-side billing cap.
