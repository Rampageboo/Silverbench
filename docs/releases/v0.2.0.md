First installable release of Silverbench.

- Install from the GitHub Release (per user, no admin rights). The app checks for updates at start and in Settings, verifies the signed installer, installs and restarts.
- The first start prepares the Python runtime (about 4 GB download: CUDA PyTorch and the rest). Later starts reinstall only when the dependencies change.
- Motion capture: the AniMocap engine is built in. Capture (single view or 2-8 separately recorded views), 2D/3D review, multiview overview, drag keyframes, per-joint lock/weight/exclude/range rebuild, undo/redo, BVH/VRMA/Blender export. Install the capture environment from the Motion capture page.
- Workspaces, settings and the gallery are unchanged; switching from the source checkout (update.bat) needs no migration.
