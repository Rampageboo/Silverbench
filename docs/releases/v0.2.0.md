第一个安装版。

- **安装与自动更新**：从 GitHub Release 下载安装包（每用户安装，不需要管理员）。应用启动时和"设置 → 关于与更新"中检查新版本，下载并校验签名后自动安装、重启。
- **首次启动**会准备 Python 运行环境（下载约 4 GB：PyTorch CUDA 等），之后只有依赖变化时才重新安装。
- **动捕**：AniMocap 引擎整合进"动捕"页——捕捉（单视角 / 2–8 个分别录制的视角）、2D/3D 回看、多视角总览、拖动关键帧、按部位锁定/加权/排除/区间重建、撤销/重做、BVH/VRMA/Blender 导出。捕捉环境在"本机环境"里一键安装。
- 工作区、设置、图库数据保持原样，从源码版（update.bat）切换过来不需要迁移。
