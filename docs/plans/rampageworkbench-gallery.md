## Shared contract (settled before delegation)

- New library implementation: `backend/gallery_library.py`, `backend/gallery_metadata.py`, `backend_api/gallery.py`; isolated worktree `.tmp/gallery-library`.
- New prompt implementation: `backend/gallery_prompts.py`, `backend/gallery_inference.py`, `config/gallery_rules.json`; isolated worktree `.tmp/gallery-prompts`.
- Root owns existing files, UI, branding, registration of router in `backend_api/main.py`, API schema bump and integration.
- Gallery router exports `router`, an APIRouter with prefix `/api/gallery`. Root adds it before the legacy static mount. SQLite and thumbnails live at `Sessions/gallery/` (ignored, SSD/local project), not within imported roots or NAS.
- Assets use content SHA256 as `id`, `path`, `filename`, `width`, `height`, `format`, `source`, `metadata` object, `rating` 0..5, `personalTags` string[], `notes` string, `collection` string, `userEdits` object, `modelTags` object, `caption` string, `createdAt`, `modifiedAt`, `missing` boolean. `metadata` fields: `format` (a1111/comfyui/novelai/none), `positive`, `negative`, `parameters` object, `model`, `loras` list, `warnings` string[], `source` = metadata/none. Store original payload without promoting inferred defaults to original.
- Prompts function: `assemble_prompts(record: dict, options: dict | None = None, rules: dict | None = None) -> dict` returns `{noobai: {positive, negative, parameters, source}, anima: {positive, negative, parameters, source}, tags: [{name, category, probability, source}], warnings: string[]}`. Options: `mode` prompt/train, `trigger`, `outfitTrigger`, `removeTags` string[], `corrections` dict, `generalThreshold`, `characterThreshold`, `captionStyle` mixed/tags/natural, `trainingKind` character/style, `sourceTag`. Use original metadata where appropriate and preserve user edits. `load_rules(path=None)` loads editable JSON; `summarize_records(records, options=None, rules=None)` provides tag frequencies/shared prefix, with no inference rerun. Library may import these functions.
- API: `GET /status` returns `{total, roots: [{id,path,source,recursive}], collections: string[], jobs: object[], capabilities: object}`; `POST /roots` body `{path,source,recursive}` registers and starts scan; `POST /scan` `{rootId?: string}`; `GET /assets` query `q,rootId,collection,minRating,hasMetadata,offset,limit` returns `{items,total,offset,limit}`; `GET /assets/{id}` returns full asset with `prompts`; `POST /assets/{id}` accepts editable fields; `GET /assets/{id}/thumbnail`, `/image` stream known indexed paths only; `GET /jobs`; `POST /jobs/{id}/{action}` actions pause/resume/cancel; `POST /export` body `{ids:string[],destination,mode,format:noobai/anima,extension:.txt/.atxt,trigger,outfitTrigger,removeTags,copyImages?:bool}` returns `{count,destination,files,warnings}`. Exports must not overwrite source images or existing files; preflight collisions and path bounds, write to explicit selected destination only. JSON/CSV manifests and dataset TOML include only selected records. HTTP errors actionable. Root can adapt frontend to implemented response.
- Do not commit, push, change remotes, rename folders, modify existing source, install dependencies or download weights in delegated lanes. Each lane writes only its listed new files and meaningful `tests/test_gallery_*.py`; verifier runs tests centrally. Both use GPT-6.1-sol / high for contained but cross-cutting persistence and prompt correctness. Report files and exact unresolved gaps.
