# 按关节修复动作

右侧“人体动作 · 按部位修复”使用有躯干、四肢和朝向提示的人体显示。
点击人体关节或用下拉框选择具体部位；白色圆环标出当前选择，正面/侧面按钮切换观察方向。
这里显示的是动作观测，单目视频的深度仍然是估计值。

## 操作

1. 捕捉完成后，选择有问题的部位，例如左手。用时间轴定位一个正确姿态，必要时先用“手动修正”拖动视频上的关节，再点击“锁定此帧”。在修复区间另一端重复一次。
2. 定位错误帧，点击“排除此部位”。也可以用“设为起点 / 设为终点”选中一段，再排除该段的这个部位；其他关节保留。
3. 将时间轴区间重新设为两个锁定帧之间，点击“重建区间”。内部没有排除的观测继续参与求解；“可信权重”可以指定当前样本为 4×、8×、16× 的软约束。
4. 用“原始叠影”对照修复前的姿态，或撤销/重做。绿色表示锁定，蓝色表示加权，红色表示排除，橙色表示重建推算。时间轴只显示当前选择部位的修复标记。
5. “恢复自动”移除当前帧或所选区间的当前部位标记。如果移除了某次重建所需的端点，也会取消那次重建。
6. “保存动作”同时保存 `.amotion` 动作包和旁边的 `.amotion.areview` 文件夹。通过“打开修复”选择 `.areview` 文件夹可继续编辑；原视频仍在原路径时会自动加载。

时间轴帧编号从 0 开始。锁定与加权只作用于当前帧；排除和恢复自动会作用于已选时间区间，没有选区时作用于当前帧。
修改一个已有锁定/加权关键点时，手动拖动会更新它的目标坐标。自动步骤则不能移动锁定目标。
编辑工程保存当前手工修正后的基线、逐关节标记和重建区间；之前的撤销栈与旧的偏移曲线不跨会话保留。

## 能力边界

- 求解器是观测空间的局部加权时序重建：保留原时间戳，使用时间连续性和可信观测，不读取被排除样本的坐标。区间外与其他关节逐值保持不变，锁定样本精确保留。
- 原始叠影指本次局部重建之前的观测基线，不是未经处理的 AI 输出。已经在识别、融合或前置平滑中传播到其他点的误差，不会被这一步倒推消除；多视角模式也不是按摄像机重新三角化。
- 连续缺失/排除段两侧支持点相隔超过 0.75 秒时拒绝求解，需要补一个可信修正点。新生成的点是推算，置信度置零，推算状态单独保存并显示，不能理解为真实观测。
- 此阶段没有增加关节角度限制、脚部接触编辑或根运动锚定。规范动作生成仍使用既有骨架重定向和脚部处理；“锁定精确”是观测编辑结果的保证，不等同于最终重定向骨架的全部世界坐标都不变。脚滑、根位置漂移和错误深度需要分别验证。
- 缺少两端锁定、无效目标、冲突重复标记或不支持的文件版本会拒绝操作。自动化测试验证约束和持久化行为，不证明真实动作精度。
